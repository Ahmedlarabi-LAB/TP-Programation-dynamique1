# TP - Programmation dynamique

Ce dépôt contient le projet de travail pour le TP de programmation dynamique.

## Description

Ce projet a pour objectif de mettre en pratique les concepts de programmation dynamique, notamment :

- optimisation de sous-problèmes
- mémorisation
- calcul récursif avec DP
- analyse de complexité

## Structure du projet

```text
.
├── README.md
├── src/
├── tests/
├── requirements.txt
└── .gitignore
```

## Prérequis

Avant de lancer le projet, assure-toi d’avoir installé :

- Python 3.x
- Git
- Un environnement virtuel (optionnel mais recommandé)

## Installation

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate      # Windows PowerShell
pip install -r requirements.txt
```

## Lancer le projet

```bash
python main.py
```

## Utilisation

Suivre les instructions spécifiques de l’énoncé du TP et exécuter les fichiers du projet selon la logique demandée.

## Exemple de commande

```bash
python src/main.py
```
